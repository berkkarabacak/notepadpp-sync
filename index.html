Notepad++ Sync

Your notes, on every laptop. No Google Drive, no OneDrive, no Dropbox.

A native Notepad++ plugin plus a tiny self-hostable server. Install, sign in, pick your folders — then just use Notepad++. Save on one laptop and the note is already there on the other.

Download GitHub

Why it's different

  • End-to-end encrypted. Files and filenames are encrypted on your device before upload. The server stores ciphertext only.
  • Real conflict handling. Simultaneous edits are detected and merged or kept — never silently overwritten.
  • Offline-first. Work without internet; changes sync when you reconnect.
  • Self-hosted or hosted. One docker compose up -d runs your own server.
  • Zero telemetry. Privacy-first, MIT licensed.

Get started

Download the release ZIP, copy NppSync.dll into Notepad++\plugins\NppSync\, restart Notepad++, and follow the one-minute setup under Plugins → Notepad++ Sync.

Self-host

git clone https://github.com/berkkarabacak/notepadpp-sync
cd notepadpp-sync
docker compose up -d
